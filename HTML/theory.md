# 1. HTML: Введение

HTML - язык гипертекстовой разметки (HyperText MarkUp Language). Описывает структуру и сематику(логику) web-страницы.
Всё то, что считается браузерами. Браузеры - движки обработки нашего кода (HTML+CSS+JS)

Приложения бывают 2 видов: тонкий клиент (приложение мало весит, оно развернутто на сервере органзации. Мы - клиенты подключаемся по протоколу HTTP/HTTPS (заходим на сайт) По сути, нам необходим лишь браузер) и толстый клиент (приложение много весит и устанавливается в оболочку ОС).
Примеры тонкого клиента: MS Teams (браузерная версия), Discord, Skype.
Примеры толстого клиента: СУБД 1С, Игры. Используются ресурсы вашего компьютера.

HTML - каркас страницы(веб-приложения) в браузере. Состоит из тегов (элементов) = блочные и строчные элементы. Внутри элеентов находится контент(текст, изображения, кнопки, списки, таблицы, формы).
Большинство тегов HTML - парные(то есть имеют открывающий тег и закрывающий тег).

Примеры парных тегов:

Примеры непарных тегов:

1. Блочный элемент - контейнер, имеющий парный тег и границы. Основные правила:
Блочный элемет по умолчанию занимает всю ширину экрана пользователя. Блочные элементы располагаются друг под другом.

Основные семантические теги:
1) Header - "Шапка сайта" Секция для вводной информации сайта или группы навигационных ссылок. Может
содержать один или несколько за оловков, логотип, информацию об авторе.
2) Main - "Тело сайта“. Контейнер для основного уникального содержимого документа. На одной странице должно
быть не более одного элемента.
З) Footep - "Подвал сайта". Определяет завершающую область (нижний колонтитул) документа или раздела.
4) Nav - Секция с навигацией (навбар).

5) Article - раздел контента, который образует независимую 
6) Section - тпределяет логическую область (раздел) страницы, обычно с заголовком.
7) Aside - Представляет контент страницы, который имеет косвенное отношение к основному контенту страницы/
сайта.
8) Div - Элемент-контейнер для разделов HTML-документа. Используется для группировки блочных элементов с целоью форматирования стилями.

Книга о тегах: https://html5book.ru/

## Формы
FROM - добавляет на страницу форму, которую пользователь может заполнить. Например, ввести своё имя, фамилию или почту. Данные формы отправляются на сервер.

    <div>

Label - добавляет текстовую метку для элемента <input>.
Input - Создает многофункциональные поля формы, в которые пользователь может вводить данные.
Button - Создает интерактивную кнопку. Элемент может содержать текст ли изображение.


У элемента <input> имеется разнообразие типов:
text, email, password, number, date, checkbox, radio, file (позволяет вложить файл из проводника)


TEXTAREA - Создает большое поле ввода текста.
SELECT - Элемент управления позволяющий выбирать значенияи з предложенного множетва. Варианты значений помещаются в <option>
OPTION - определяет вариант/опцию для выбора в раскрывающемся списке <select>, <optgroup> и <datalist>.


## Атрибуты элеметов html
src="..." - Путь к изображению/скрипту/видео
<img src="...">
<scrtip src="./js.js">

href="..." - Адрес ссылки
<a href="...">

alt="..." - Текстовое описание (исп. для изображений)
<img src="" alt="">

title="..." - дополнительная всплывающая подсказка

name="..." - Имя поля при отправке формы (атрибут для <input>)
<input type="text" name="..." value="...">

value="..." - Значение поля
<input value="...">

type="..." - Тип кнопки или поля ввода (применяется к <button> или к <input>)

placeholder="..." - Короткая подсказка внутри поля <input>

required - Обязательное поле
<input type="text" name="..." placeholder="Введите логин" required>

disabled - отключенный элемент

checked - Выбранный checkbox/radio (у элементов <button>)

class - позволяет идентифицировать элемент CSS-классом (может повторяться у разных элементов)
<div class="first">Первый блок</div>
<div class="second"> Второй блок</div>

id - позволяет идетнифицировать элемент (чаще использую для JS-скриптов). Может повторяться у разныъ элементов.
<div id="firstId">Первый блок</div>
<div class="secondId">Второй блок</div>

## Каскадные таблицы стилей

Подключение файла стилей к .html документу
CSS (Cascading Style Sheets) — язык таблиц стилей, который позволяет прикреплять стиль (например, шрифты и цвет) к структурированным документам (например, документам HTML и приложениям XML).

Обычно CSS-стили используются для создания и изменения стиля элементов веб-страниц и пользовательских интерфейсов, написанных на языках HTML и XHTML,
но также могут быть применены к любому виду XML-документа, в том числе XML, SVG и XUL.

Стили CSS подключаются внутри <head> (в конце)
Команда подключения: <link rel="styulesheet" href="./css/styles.css">

Имена записываются латиницей в нижнем регистре.
Для разделения слов в именах используется дефис(-).
Имена блока задает пространство имен для его элементов и модификаторов.
Имена элемента отделяется от имени блока двумя подчеркиваниями(__).
Имя модификатора отделяется от имени блока или элемента одним подчеркиванием (_).
Значение модификатора отедляется от имени модификатора одним подчеркиванием (_).
Значение булевых модификаторов в имени не указывается.
